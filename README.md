# Amrit-Palace

> **A Place for Every Occasion — Lohardaga, Jharkhand**

Amrit Palace is a luxury hospitality web application offering immersive stays, grand celebrations, dining experiences, and corporate gatherings.

## ✨ Features
- **Cinematic Hero**: Real architectural integration with dynamic blue-hour lighting and interactive visual storytelling.
- **Kinetic Services Typography**: Auto-cycling editorial typography showcase with real-time gradient evolution and delicate stardust effects.
- **Responsive Design**: Tailored experiences for desktop and mobile viewports.
- **Modern Stack**: React 19, TypeScript, Vite, and Tailwind CSS.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
