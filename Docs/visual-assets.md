# Amrit Palace — Visual Assets Guide

## 1. Purpose

This document tells the project how to think about, organise and use the visual assets for the Amrit Palace demo.

The public website is highly visual, so assets are not decoration added after development.

They are part of the product experience.

The visual system should make Amrit Palace feel:

- Cinematic
- Warm
- Authentic
- Modern
- Memorable
- Welcoming
- Full of life

The goal is to use the real property and real visual identity as the foundation, then enhance the presentation through thoughtful composition, motion and interaction.

---

# 2. Asset Philosophy

The website should communicate the feeling of being at Amrit Palace before asking visitors to read large amounts of information.

Prioritise:

**Real property → Real atmosphere → Real people / occasions → Real food → Brand**

Use imagery with intention.

A visual should have a role in the story:

- Establish the property
- Create desire
- Explain a service
- Introduce an occasion
- Make food appealing
- Establish trust
- Transition between experiences
- Reinforce the brand

---

---

# 4. Cinematic Film

The current film is approximately:

- 32.7 seconds
- 30fps
- 1920 × 1080
- Approximately 982 frames

The extracted frame archive contains the complete frame sequence.

Use cases can include:

- Hero film
- Scroll-driven image sequence
- Section transitions
- Cinematic background
- Preloader / arrival sequence
- Visual storytelling
- Transition into the brand reveal

Antigravity can choose the strongest technical treatment based on performance and visual quality.

---

# 5. Film Narrative

The existing film can be understood as a visual journey:

```text
Exterior Arrival
      ↓
Approach to Property
      ↓
Entrance / Lobby
      ↓
Interior / Venue
      ↓
Wedding / Celebration
      ↓
Birthday / Gathering
      ↓
Meeting / Professional Occasion
      ↓
Amrit Palace Brand Reveal
```

This sequence supports the wider website story:

**STAY → DINE → CELEBRATE → MEET**

The film should feel like one continuous world.

---

# 6. Exterior Assets

Exterior photography and video should establish:

- The physical property
- Entrance
- Architecture
- Arrival
- Surroundings
- Brand presence
- Sense of place

Strong exterior assets can be used for:

- Hero sections
- Arrival sequences
- About section
- Location section
- Transitions
- Footer / closing moments

Where multiple exterior photographs exist, choose based on lighting, composition and storytelling value rather than simply using every available image.

---

# 7. Interior Assets

Interior assets should communicate:

- Hospitality
- Comfort
- Architecture
- Banquet / event space
- Atmosphere
- Practicality
- Scale

Potential uses:

- Venue introduction
- Room section
- Services
- Event pages
- About
- Background transitions
- Gallery

Use large imagery where the architecture benefits from space.

---

# 8. Room Assets

Room imagery should represent the actual room offering.

Amrit Palace currently has one room type.

Relevant visual subjects include:

- Bed
- Room interior
- Air-conditioning
- Television where present
- Furnishings
- Lighting
- Bathroom / facilities where actual imagery exists

The website should present the real room confidently without creating fictional room categories or features.

---

# 9. Food Assets

Food imagery deserves especially high visual priority.

The dining experience should make the food feel:

**Fresh. Warm. Rich. Desirable.**

Strong food assets should be used for:

- Public dining section
- Guest menu
- Dish cards
- Dish detail views
- Featured dishes
- Category transitions
- Food ordering
- Promotional moments

Give high-quality food photographs enough scale to create appetite.

A tiny image inside a generic card should not be the default when a stronger composition is possible.

---

# 10. Food Image Treatment

Food imagery can be presented through:

- Large editorial cards
- Full-bleed images
- Layered compositions
- Horizontal galleries
- Immersive detail views
- Image reveals
- Hover zoom
- Subtle parallax
- Motion transitions
- Cropped close-ups

The interface should use restraint around the photography so the food remains the visual star.

The goal is:

**The guest sees a dish and immediately wants to order it.**

---

# 11. Event Assets

Event imagery communicates what Amrit Palace can make possible.

Important visual categories:

### Weddings

Use culturally authentic Indian wedding imagery.

The visual language should communicate:

- Family
- Celebration
- Togetherness
- Ceremony
- Colour
- Joy

Keep the atmosphere culturally appropriate and family-oriented.

### Birthdays

Use imagery communicating:

- Family
- Children
- Cake
- Balloons
- Celebration
- Shared moments

### Meetings

Use professional Indian business / conference imagery communicating:

- Focus
- Collaboration
- Professionalism
- Presentation
- Gathering

The event imagery should feel like a natural extension of Amrit Palace rather than disconnected stock photography.

---

# 12. People in Visuals

People are important because hospitality is ultimately about people.

Where generated imagery is used, it should feel culturally appropriate to the context of Amrit Palace and the audience it serves.

For Indian wedding and family scenes, use authentic Indian styling, environments and behaviour.

Avoid visuals that accidentally communicate the wrong occasion.

For example, a wedding experience should feel like a celebration involving families and guests rather than suggesting a private honeymoon or romantic hotel-room sequence.

---

# 13. Generated Visuals

Generated assets can be used when real photography is unavailable or when a particular visual transition requires something that cannot reasonably be captured.

Generated visuals should be grounded in the actual Amrit Palace identity.

Use them to extend the visual language rather than replace the property's identity.

When creating new visual assets:

- Match the real architectural character
- Respect the actual branding
- Keep Indian cultural context authentic
- Maintain believable hospitality environments
- Use the established warm / refined visual language
- Create assets that can naturally coexist with real photography

---

# 14. Real vs Generated Asset Strategy

Prefer:

**Real Amrit Palace assets for the property itself.**

Use generated assets where they provide value for:

- Conceptual storytelling
- Missing occasion imagery
- Atmospheric transitions
- Visual experimentation
- Cinematic sequences

The combination should feel coherent.

Visitors should experience one visual world rather than notice which images came from which source.

---

# 15. Branding Assets

Branding should remain consistent across the entire experience.

Primary identity:

**AMRIT PALACE**

Tagline:

**A PLACE FOR EVERY OCCASION**

The dedicated brand-film moment should resolve into this identity before the footer.

Use the official logo / branding asset wherever available rather than recreating it unnecessarily.

---

# 16. Dedicated Brand Film

The dedicated closing brand clip is separate from the occasion storytelling.

Its purpose is brand reinforcement.

It should contain:

**AMRIT PALACE**

**A PLACE FOR EVERY OCCASION**

It should not become another montage of weddings, birthdays and meetings.

The brand reveal should feel like the final signature of the experience.

---

# 17. Colour Relationship

The cinematic film contains multiple environmental colour palettes:

- Exterior daylight / sunset tones
- Warm interior tones
- Wedding reds and festive colours
- Birthday colours
- Professional meeting environments
- Dark brand-reveal tones

The interface should not attempt to compete with every colour present in the footage.

Instead:

**Video = emotion and environment**

**UI = calm architectural layer**

Use a restrained interface palette built around:

- Ivory / cream
- Warm neutrals
- Charcoal / deep tones
- Restrained champagne / gold accents
- Transparent glass surfaces where appropriate

The UI should frame the imagery rather than fight it.

---

# 18. Glassmorphism

Glass should be used as a refined architectural material.

Appropriate uses include:

- Navigation
- Floating controls
- Contextual overlays
- Selected cards
- CTA surfaces
- Information layers

Use transparency, blur, borders, shadow and spacing carefully.

The purpose is to create depth and separation while allowing the photography and video to remain visible.

---

# 19. Asset Naming

Use predictable filenames.

Examples:

```text
exterior-01.jpg
exterior-arrival.jpg
lobby-01.jpg
banquet-hall-01.jpg
room-01.jpg
food-paneer-01.jpg
food-biryani-01.jpg
wedding-01.jpg
birthday-01.jpg
meeting-01.jpg
logo.svg
brand-film.mp4
```

Avoid filenames such as:

```text
IMG_4839.jpg
finalfinal2.png
new-new-video.mp4
```

when the asset can be named meaningfully.

---

# 20. Asset Metadata

Where practical, maintain enough information to understand:

- Subject
- Location
- Category
- Source
- Orientation
- Resolution
- Intended section
- Whether it is real or generated

This becomes increasingly useful as the visual library grows.

---

# 21. Image Selection

Do not use assets simply because they exist.

Choose imagery based on:

1. Story relevance
2. Composition
3. Lighting
4. Authenticity
5. Image quality
6. Visual continuity
7. Responsive crop potential

A smaller set of excellent images is more valuable than a large collection of mediocre ones.

---

# 22. Video Selection

Use video where motion adds emotional or spatial value.

Strong uses include:

- Arrival
- Property reveal
- Event atmosphere
- Brand reveal
- Major section transitions

Avoid using motion simply because the technology allows it.

Every moving asset should have a reason to exist.

---

# 23. Frame Sequence Usage

The 30fps frame archive can support highly controlled cinematic interactions.

Potential implementation:

```text
Scroll Position
      ↓
Frame Progress
      ↓
Selected Video Frame
      ↓
Canvas / Image
```

This can create the feeling that the visitor is physically moving through the property as they scroll.

The implementation should remain performance-conscious, particularly on mobile.

---

# 24. Responsive Asset Strategy

Desktop and mobile do not need to use identical asset treatments.

Antigravity can select:

- Different crops
- Alternate images
- Shorter video
- Static poster frames
- Reduced frame sequences
- Mobile-specific compositions

The goal is to preserve the intended emotional experience on every device.

---

# 25. Asset Loading

Visual assets should be loaded intentionally.

Consider:

- Preloading critical hero media
- Lazy loading below-the-fold images
- Responsive image sizes
- Modern image formats
- Poster images for video
- Progressive loading
- Reduced-motion alternatives
- Mobile-specific media

The visitor should see something beautiful quickly while heavier assets continue loading intelligently.

---

# 26. Image Accessibility

Meaningful informational images should have useful alternative text.

Decorative imagery can be treated as decorative.

The visual experience should remain accessible without destroying its cinematic character.

# 28. Guest Portal Assets

The guest portal should use visual assets selectively.

High-value areas:

- Food menu
- Food detail
- Stay overview
- Booking confirmation
- Event context

The guest portal should remain functional, so imagery should support usability rather than overwhelm it.

---

# 29. Chef Portal Assets

The chef portal has a much more operational purpose.

Food thumbnails can help identify dishes quickly.

Inventory should primarily use clear information and visual status indicators.

Large cinematic photography is generally more useful in the public and guest experiences than inside operational workflows.

---

# 30. Admin Portal Assets

Admin should use imagery where it provides context:

- Menu management
- Event management
- Property overview

The admin dashboard should primarily focus on information and operational clarity.

---

# 31. Asset Quality Bar

Before an asset enters the primary experience, ask:

**Does this make Amrit Palace look more believable, more desirable or more memorable?**

If the answer is no, find a stronger asset or a better treatment.

---

# 32. Visual North Star

The final website should feel like someone took the real Amrit Palace and translated its atmosphere into a modern digital world.

Not a generic hotel template.

Not a collection of stock images.

Not a gallery pasted onto a dashboard.

Instead:

**A cinematic digital expression of a real place where people stay, eat, celebrate and meet.**

The visuals should make visitors want to come.

The food should make them hungry.

The events should make them imagine their occasion there.

The brand reveal should make the experience feel complete.

**AMRIT PALACE**

**A PLACE FOR EVERY OCCASION**
